Radically accurate. Radically cheap. Radically easy to self-host.

Get started

What you need to do

  1. 1Clone the repository and set TOGETHER_API_KEY in .env.
  2. 2Run docker compose up -d --build.
  3. 3Copy-paste the code snippet to call your API.

How it works

  • The code snippet is a simple HTTPS request that sends the resume to your API.
  • Text is read from the PDF; scanned pages are OCR'd automatically.
  • An LLM fills a strict JSON schema, and the result is validated before it is returned.
  • Experience is calculated in code, merging overlapping roles so nothing is double counted.

Details

  • Accepted format: .pdf, up to 10 MB and 10 pages (configurable).
  • Accepted content: resumes in any language. Other documents are rejected.
  • Typical latency: 2–5 seconds per resume, about $0.001 in model cost.

Private by design

  • Nothing is stored: files are processed in memory and discarded once the response is sent.
  • You host it: run it in your own cloud, region, and network.
  • Resume text is sent only to the Together AI model you configure, never to third-party hosted models.

Extracted data

The API returns a JSON object with:

  • profile: an object with all the extracted data.
  • cv_language: the language of the CV.
  • cv_text: the full text of the CV.

When some profile data is not found in the original CV:

  • String value is set to "" by default.
  • Integer value is set to null by default.
  • Enum value is set to null by default.
